# Symbols

Every icon is an SF Symbol. Draw one with `<span class="sf" data-symbol="NAME"></span>` after loading `symbols.css`; it takes `currentColor`. Sizes: `sf--sm` 16, `sf--md` 20, `sf--lg` 24. SF Symbols are Apple's, licensed for apps on Apple platforms.

## Symbols (51)

SF Symbols exported as vector SVG from the SF Symbols app (Regular weight, 24pt, monochrome). File names are the symbol names. Each file's single ink is `#1a1a2e` (`color-text-primary`); to tint one, draw it through the `.sf` mask class so it takes `currentColor`. The `.circle.fill` symbols keep their cut-out glyph as a mask, so they work on any background.

SF Symbols are Apple's and are licensed for designing and building apps on Apple platforms. Don't use them in logos.

Names: `arrow.trianglehead.clockwise`, `arrow.up.circle.fill`, `arrow.up.right.square`, `bell`, `bolt.fill`, `bubble.left`, `calendar`, `camera`, `checkmark`, `checkmark.circle.fill`, `chevron.down`, `chevron.left`, `chevron.left.forwardslash.chevron.right`, `chevron.right`, `chevron.up`, `document`, `document.on.document`, `ellipsis`, `ellipsis.circle`, `exclamationmark.circle`, `exclamationmark.triangle`, `gearshape`, `globe`, `hand.thumbsdown`, `hand.thumbsup`, `house`, `info.circle`, `line.3.horizontal.decrease`, `lock`, `magnifyingglass`, `microphone`, `minus`, `moon`, `paperclip`, `paperplane.fill`, `pencil`, `person`, `photo`, `plus`, `sidebar.left`, `sparkles`, `speaker.wave.2`, `square.and.arrow.down`, `square.and.arrow.up`, `square.and.pencil`, `star`, `stop.fill`, `trash`, `waveform`, `xmark`, `xmark.circle.fill`

## Calendar (37)

SF Symbols for calendar and scheduling apps, exported from the SF Symbols app's names (SF Symbols 27) at Regular weight, 24pt, as vector SVG. File names are the symbol names. The single ink is `#1a1a2e` (`color-text-primary`); draw them through the `.sf` mask class to tint with `currentColor`. Badge symbols (`calendar.badge.*`, `bell.badge`, `person.badge.plus`, `globe.badge.clock`) keep Apple's cut-out gaps as SVG masks. See the CalendarSymbols card for which symbol means what. SF Symbols are licensed by Apple for apps on Apple platforms.

### Meanings

- **Views:** `square.grid.3x3` (month), `rectangle.split.3x1` (week), `calendar.day.timeline.left` (day), `list.bullet` (agenda), `calendar` (today, in Symbols).
- **Event actions:** `calendar.badge.plus` (new), `calendar.badge.checkmark` (accepted), `calendar.badge.minus` (declined or removed), `calendar.badge.exclamationmark` (conflict), `calendar.badge.clock` (pending or tentative).
- **Event details:** `clock`, `location`, `person.2` (attendees), `person.badge.plus` (invite), `video` and `phone` (call links), `envelope`, `text.pad.header` (notes), `checklist`, `flag`, `pin`.
- **Time and reminders:** `alarm`, `bell.badge` (unread alert), `bell.slash` (muted), `timer`, `hourglass`, `deskclock`, `repeat` (recurring), `clock.arrow.trianglehead.counterclockwise.rotate.90` (history), `globe.badge.clock` (time zone).
- **Occasions:** `birthday.cake`, `gift`, `party.popper`.

## Travel (54)

SF Symbols for travel apps (flights, transport, stays, maps, documents, money, weather), exported from the SF Symbols app's names (SF Symbols 27) at Regular weight, 24pt, as vector SVG. File names are the symbol names. The single ink is `#1a1a2e` (`color-text-primary`); draw them through the `.sf` mask class to tint with `currentColor`. See the TravelSymbols card for which symbol means what. `airplane.ticket.perforated` and `ticket.perforated` are left out: they need macOS 27.2 to export. SF Symbols are licensed by Apple for apps on Apple platforms.

### Meanings

- **Flights:** `airplane`, `airplane.departure`, `airplane.arrival`, `airplane.landed`, `airplaneseat`, `clock.badge.airplane` (flight time).
- **Ground and water:** `car`, `bus`, `train.side.front.car`, `tram`, `ferry`, `car.ferry`, `sailboat`, `bicycle`, `figure.walk`, `fuelpump`.
- **Stay and eat:** `bed.double` (hotel), `building.2` (city stay), `house.lodge`, `tent`, `fork.knife`, `cup.and.saucer`, `wineglass`.
- **Plan and navigate:** `map`, `mappin`, `mappin.and.ellipse`, `location.north`, `signpost.right`, `globe.americas` / `globe.europe.africa` / `globe.asia.australia` (pick the traveller's region), `list.clipboard` (itinerary).
- **Bags and documents:** `suitcase`, `suitcase.rolling`, `figure.walk.suitcase.rolling`, `person.text.rectangle` (passport or ID), `ticket`, `wallet.pass`, `qrcode`.
- **Money:** `creditcard`, `banknote`, `dollarsign.arrow.trianglehead.counterclockwise.rotate.90` (exchange).
- **On the ground:** `translate`, `wifi`, `powerplug`, `binoculars`, `mountain.2`, `beach.umbrella`.
- **Weather:** `sun.max`, `cloud.sun`, `cloud.rain`, `snowflake`, `umbrella`, `thermometer.medium`.
