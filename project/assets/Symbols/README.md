# Symbols

SF Symbols exported as vector SVG from the SF Symbols app (Regular weight, 24pt, monochrome). File names are the symbol names. Each file's single ink is `#1a1a2e` (`color-text-primary`); to tint one, draw it through the `.sf` mask class so it takes `currentColor`. The `.circle.fill` symbols keep their cut-out glyph as a mask, so they work on any background.

SF Symbols are Apple's and are licensed for designing and building apps on Apple platforms. Don't use them in logos.
