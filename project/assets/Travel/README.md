# Travel

SF Symbols for travel apps (flights, transport, stays, maps, documents, money, weather), exported from the SF Symbols app's names (SF Symbols 27) at Regular weight, 24pt, as vector SVG. File names are the symbol names. The single ink is `#1a1a2e` (`color-text-primary`); draw them through the `.sf` mask class to tint with `currentColor`. See the TravelSymbols card for which symbol means what. `airplane.ticket.perforated` and `ticket.perforated` are left out: they need macOS 27.2 to export. SF Symbols are licensed by Apple for apps on Apple platforms.
