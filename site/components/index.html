Components

Components

Components follow Apple's HIG names and behaviour, styled with Arlo's tokens. Classes live in components/bundle.css (prefix ar-); each component's card has its guidelines.

Menus and actions

Button

A button starts an action; Arlo buttons follow Apple's styles (filled, tinted, gray, plain) with one fixed 12px corner, radius-button.

Menu

A menu lists actions or options in a temporary panel opened from a button, a pop-up button or a right-click (Apple: menus, context menus, pull-down buttons).

Pop-up button

A pop-up button shows the current choice from a short, mutually exclusive list and opens a menu to change it (Apple: pop-up buttons).

Selection and input

Checkbox

A checkbox turns an option on or off inside a form that is confirmed later (Apple: checkboxes, macOS).

Radio button

Radio buttons choose exactly one option from a small, visible set (Apple: radio buttons, macOS).

Segmented control

A segmented control switches between 2–5 closely related views or modes (Apple: segmented controls); it replaces Arlo's pill Tabs.

Slider

A slider picks a value from a continuous range (Apple: sliders).

Stepper

A stepper raises or lowers a value by a fixed amount (Apple: steppers).

Text field

A text field takes a short line of text; a multiline field takes paragraphs (Apple: text fields, text views).

Toggle

A toggle switches one setting on or off with immediate effect (Apple: toggles / switches).

Navigation and search

Navigation bar

A navigation bar sits at the top of a view: where you are, how to go back, and the view's main actions (Apple: navigation bars and toolbars).

Page control

A page control shows how many pages a horizontally paged view has and which one is showing (Apple: page controls), such as onboarding.

Search field

A search field filters or finds content (Apple: search fields).

Sidebar

A sidebar lists an app's top-level sections and collections on medium and wider windows (Apple: sidebars).

Tab bar

A tab bar switches between the top-level sections of an app on compact windows (Apple: tab bars).

Layout and organization

List

Lists present rows of related content: settings, conversations, files (Apple: lists and tables, inset grouped style); it replaces Arlo's Table in app UI.

Presentation

Alert

An alert interrupts to report a problem or confirm a consequential action (Apple: alerts); it replaces Arlo's Dialog for short decisions.

Popover

A popover shows transient detail or a few controls anchored to the element that opened it (Apple: popovers); help tags are the hover-only variant, replacing Arlo's Tooltip.

Sheet

A sheet presents a focused task that relates to the current view, such as creating or editing something (Apple: sheets).

Status

Badge

Badges label status or category in a few words; count badges show unread or pending numbers.

Progress indicator

Progress indicators show that work is happening: a bar or ring when the amount is known, a spinner when it isn't (Apple: progress indicators).

Content

Symbol

Every interface icon is an SF Symbol, drawn by the .sf class as a mask tinted by currentColor, so a symbol takes the colour of the text around it.
